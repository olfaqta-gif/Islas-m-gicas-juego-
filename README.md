# Fabi, Cami y Vale: Las Islas Mágicas

Juego de aprendizaje para niñas pequeñas: tres primas viajan por islas mágicas y juegan con colores, formas, números, letras y más. Las voces y la música ya están grabadas y no se descargan mientras se juega.

Para jugar en el teléfono en pantalla completa: abre el link en Safari, toca Compartir y luego "Agregar a pantalla de inicio".
